一、能流、功率与辐射压
#

从单位面积的能流到总功率
#

坡印廷矢量 S\mathbf SS 表示电磁波的能流密度。若波垂直穿过所选面积，用 Sˉ\bar SSˉ 表示其平均能流密度的大小，单位是 W/m2\mathrm{W/m^2}W/m2；辐射通量（辐射功率）PPP 的单位则是 W\mathrm WW。一般情况下应对面积积分：

P=∫AS⋅dA P=\int_A\mathbf S\cdot\mathrm d\mathbf A P=∫A​S⋅dA

如果面积上能流均匀，且波垂直穿过面积 AAA，可以简化为 Sˉ=P/A\bar S=P/ASˉ=P/A。对于向外均匀辐射、传播中无损耗的球面波，在半径 RRR 的球面上还有

P=4πR2Sˉ(R) P=4\pi R^2\bar S(R) P=4πR2Sˉ(R)

场强与辐射压
#

对于真空中的正弦平面电磁波，电场、磁场的振幅分别为 E0E_0E0​、B0B_0B0​，则

Sˉ=12ϵ0cE0,B0=E0c \bar S=\frac12\epsilon_0cE_0^, \qquad B_0=\frac{E_0}{c} Sˉ=21​ϵ0​cE0,​B0​=cE0​​

光束垂直入射物体表面时，压强还取决于表面如何处理入射光：

p={Sˉ/c,完全吸收,2Sˉ/c,理想全反射. p=\begin{cases} \bar S/c,&\text{完全吸收},\\ 2\bar S/c,&\text{理想全反射}. \end{cases} p={Sˉ/c,2Sˉ/c,​完全吸收,理想全反射.​

全反射时动量方向反转，所以压强是完全吸收时的两倍。

二、干涉：先找相位差，再算强度
#

设两列同频相干波在同一种介质中传播，到观察点的距离为 r1,r2r_1,r_2r1​,r2​。先写出每列波在该点引起的振动：

yi=Aicos⁡(ωt+φi0−2πλri),i=1,2 y_i=A_i\cos(\omega t+\varphi_{i0}- \frac{2\pi}{\lambda} r_i),\qquad i=1,2 yi​=Ai​cos(ωt+φi0​−λ2π​ri​),i=1,2

φ10\varphi_{10}φ10​、φ20\varphi_{20}φ20​ 各自是波源的初相位；它们的差才是初相位差。因此，两列波到达观察点的相位差为

Δφ=(φ10−φ20)−2πλ(r1−r2) \Delta\varphi=(\varphi_{10}-\varphi_{20})-\frac{2\pi}{\lambda}(r_1-r_2) Δφ=(φ10​−φ20​)−λ2π​(r1​−r2​)

在两列波相干、振动方向一致（对光还要注意偏振方向）的条件下，合成强度为

I=I1+I2+2I1I2cos⁡Δφ I=I_1+I_2+2\sqrt{I_1I_2}\cos\Delta\varphi I=I1​+I2​+2I1​I2​​cosΔφ
  • 极大（相长）： Δφ=2mπ\Delta\varphi=2m\piΔφ=2mπ，此时 Imax⁡=(I1+I2)2I_{\max}=(\sqrt{I_1}+\sqrt{I_2})^2Imax​=(I1​​+I2​​)2。
  • 极小（相消）： Δφ=(2m+1)π\Delta\varphi=(2m+1)\piΔφ=(2m+1)π，此时 Imin⁡=(I1−I2)2I_{\min}=(\sqrt{I_1}-\sqrt{I_2})^2Imin​=(I1​​−I2​​)2。

这里 mmm 是整数。只有 I1=I2I_1=I_2I1​=I2​ 时，相消的极小值才为零；同频也不自动意味着两列波相干。

三、反射与驻波：先辨传播方向
#

沿 +x+x+x 和 −x-x−x 方向传播的波，可分别写成

y+(x,t)=Acos⁡(ωt−kx+φ+),y−(x,t)=Acos⁡(ωt+kx+φ−) y_+(x,t)=A\cos(\omega t-kx+\varphi_+),\qquad y_-(x,t)=A\cos(\omega t+kx+\varphi_-) y+​(x,t)=Acos(ωt−kx+φ+​),y−​(x,t)=Acos(ωt+kx+φ−​)

相位中 xxx 前面的正负号由传播方向决定。例如波从 x0x_0x0​ 向左传播时，到达 x<x0x<x_0x<x0​ 的路程是 x0−xx_0-xx0​−x，故可写成 Acos⁡[ωt−k(x0−x)+φ0]A\cos[\omega t-k(x_0-x)+\varphi_0]Acos[ωt−k(x0​−x)+φ0​]。

反射是否多出 π\piπ 的相位，要看边界与所讨论的波：弦上的横波在固定端反射会反相，在自由端不会；光的电场在正入射、从低折射率介质一侧射向高折射率介质并反射时会有 π\piπ 相变。

两列相干、同频、等振幅、反向传播的波叠加，才会形成这里讨论的典型驻波。选取合适的坐标原点和初相位，一个例子是

y=−2Acos⁡(2πxλ)sin⁡(2πνt) y=-2A\cos\left(\frac{2\pi x}{\lambda}\right)\sin(2\pi\nu t) y=−2Acos(λ2πx​)sin(2πνt)

判断波节、波腹时，看的是位置因子 cos⁡(2πx/λ)\cos(2\pi x/\lambda)cos(2πx/λ)：

波节：cos⁡(2πxλ)=0波腹：∣cos⁡(2πxλ)∣=1,m∈Z \begin{aligned} \text{波节：}&\quad \cos\left(\frac{2\pi x}{\lambda}\right)=0 \\ \text{波腹：}&\quad \left|\cos\left(\frac{2\pi x}{\lambda}\right)\right|=1 ,\qquad m\in\mathbb Z \end{aligned} 波节：波腹：​cos(λ2πx​)=0​cos(λ2πx​)​=1,m∈Z​

四、多普勒效应与拍频：分清谁在动
#

以下是**有介质的波（如声波）**的经典多普勒公式。设波相对介质的速度为 uuu，波源频率为 ν0\nu_0ν0​，观察者和波源沿连线方向的速率大小分别为 vO,vSv_O,v_SvO​,vS​：

νobs=ν0u±vOu∓vS \nu_{\mathrm{obs}}=\nu_0\frac{u\pm v_O}{u\mp v_S} νobs​=ν0​u∓vS​u±vO​​
  • 观察者靠近 / 远离波源： 分子分别取 u+vOu+v_Ou+vO​ / u−vOu-v_Ou−vO​。
  • 波源靠近 / 远离观察者： 分母分别取 u−vSu-v_Su−vS​ / u+vSu+v_Su+vS​。

例如观察者靠近静止波源时，νobs=(u+vO)ν0/u\nu_{\mathrm{obs}}=(u+v_O)\nu_0/uνobs​=(u+vO​)ν0​/u；波源靠近静止观察者时，νobs=uν0/(u−vS)\nu_{\mathrm{obs}}=u\nu_0/(u-v_S)νobs​=uν0​/(u−vS​)。原来分母的 u+vSu+v_Su+vS​ 对应的是波源远离观察者。这组经典公式不能直接用于真空中的光。

拍频则是另一件事：两列频率接近的波叠加时，振幅会缓慢起伏，其拍频是频率差的绝对值：

νbeat=∣νa−νb∣ \nu_{\mathrm{beat}}=|\nu_a-\nu_b| νbeat​=∣νa​−νb​∣
