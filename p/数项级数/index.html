一、 核心概念与定义
#

  • 数项级数：给定数列 {xn}\{x_n\}{xn​}，其各项依次相加的表达式 ∑n=1∞xn\sum_{n=1}^{\infty}x_n∑n=1∞​xn​ 称为数项级数（或无穷级数）。

  • 部分和 (SnS_nSn​)：级数前 nnn 项的和 Sn=x1+x2+⋯+xnS_n = x_1 + x_2 + \dots + x_nSn​=x1​+x2​+⋯+xn​ 。

  • 收敛与发散：

    • 若部分和数列 {Sn}\{S_n\}{Sn​} 的极限存在（即 lim⁡n→∞Sn=S\lim_{n\to\infty} S_n = Slimn→∞​Sn​=S），则称级数收敛，且 SSS 为其和 。

    • 若极限不存在，则称级数发散 。

二、 级数的基本性质
#

收敛的必要条件：若级数 ∑xn\sum x_n∑xn​ 收敛，则通项必趋于 0，即 lim⁡n→∞xn=0\lim_{n\to\infty} x_n = 0limn→∞​xn​=0 。

注意：这只是必要条件而非充分条件。例如调和级数 ∑1n\sum \frac{1}{n}∑n1​ 虽然通项趋于 0，但它是发散的 。

  • 线性性质：若 ∑xn\sum x_n∑xn​ 和 ∑yn\sum y_n∑yn​ 都收敛，则它们的线性组合 ∑(λxn+μyn)\sum (\lambda x_n + \mu y_n)∑(λxn​+μyn​) 也收敛 。

  • 有限项原则：增加、去掉或改变级数中的有限项，不改变级数的敛散性 。

  • 加括号性质：收敛级数任意加括号后得到的新级数仍收敛，且和不变 。

三、 重要参考级数
#

在判别敛散性时，常作为“标尺”的两个级数：

  1. 等比级数（几何级数） ∑qn\sum q^n∑qn：当且仅当 ∣q∣<1|q|< 1∣q∣<1 时收敛 。

  2. p-级数 ∑1np\sum \frac{1}{n^p}∑np1​：当且仅当 p>1p > 1p>1 时收敛 。

四、 正项级数的判别法
#

正项级数是指各项均满足 xn≥0x_n \ge 0xn​≥0 的级数 。

  • 充要条件：正项级数收敛的充要条件是其部分和数列 {Sn}\{S_n\}{Sn​} 有上界 。
  • 比较判别法：设 0≤xn≤yn0 \le x_n \le y_n0≤xn​≤yn​ ：
  • 若“大”的级数 ∑yn\sum y_n∑yn​ 收敛，则“小”的级数 ∑xn\sum x_n∑xn​ 必收敛 。
  • 若“小”的级数 ∑xn\sum x_n∑xn​ 发散，则“大”的级数 ∑yn\sum y_n∑yn​ 必发散 。
  • 极限形式的比较判别法：考虑 lim⁡n→∞xnyn=l\lim_{n\to\infty} \frac{x_n}{y_n} = llimn→∞​yn​xn​​=l ：
  • 若 lll 为正实数，则 ∑xn\sum x_n∑xn​ 与 ∑yn\sum y_n∑yn​ 同敛散 。
  • 若 l=0l = 0l=0 且 ∑yn\sum y_n∑yn​ 收敛，则 ∑xn\sum x_n∑xn​ 收敛 。
  • 若 l=+∞l = +\inftyl=+∞ 且 ∑yn\sum y_n∑yn​ 发散，则 ∑xn\sum x_n∑xn​ 发散 。

五、常用判断技巧总结
#

判断级数敛散性的思路：

  1. 先看通项是否→0（不趋于0直接发散）
  2. 能求部分和就直接求极限
  3. 正项级数 → 用比较判别法或其极限形式 （与 1/n^p 或 q^n 比较）
  4. 通项含阶乘/幂次 → 后续章节的比值/根值判别法
